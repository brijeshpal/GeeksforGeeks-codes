# GeeksforGeeks Codes

A collection of my solutions to **Data Structures and Algorithms (DSA)** problems on [GeeksforGeeks](https://www.geeksforgeeks.org/), organized by difficulty level.

Solutions are synced to this repository automatically with the **[GfG To GitHub](https://github.com/AtharvaNanavate/GfG-To-GitHub)** browser extension: every time I solve a problem on GeeksforGeeks, the code is pushed here.

## Repository Structure

Problems are grouped into folders by GeeksforGeeks difficulty level. Each problem has its own folder with the solution file and a `README.md` containing the problem statement.

```
.
├── Difficulty: School/
├── Difficulty: Basic/
├── Difficulty: Easy/
│   └── <Problem Name>/
│       ├── README.md          # Problem statement
│       └── <solution-file>    # My solution
├── Difficulty: Medium/
├── Difficulty: Hard/
└── README.md
```

## Difficulty Levels

| Level | Description |
|-------|-------------|
| **School** | Very basic problems to get started with programming |
| **Basic** | Simple logic and fundamental concepts |
| **Easy** | Standard problems on core data structures |
| **Medium** | Problems that need a good grasp of algorithms and patterns |
| **Hard** | Advanced problems needing optimized and creative solutions |
